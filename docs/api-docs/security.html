Security Guide

Reference › Security

FlexTemplates ships with four security layers active by default: opt-out JWT auth on every /v1/ route, rate limiting on login and all protected endpoints, CORS policy, and a strict-mode guard that prevents deploying with a dev JWT secret.

🔒 All security env vars live in .secrets/.env — never in the project root .env. AppConfig reads from .secrets/.env automatically.

How routes are protected

Every /v1/ route passes through one of two sub-routers built by make_v1_router(config) in lib/api/v1.py:

Sub-routerWho uses itEnforces
public lib/api/routes/auth.py only Login rate limit
protected Every other route module General rate limit + Bearer JWT

The default is protected. A new file dropped in lib/api/routes/ is automatically in the protected sub-router — no Depends(get_current_user) needed. The only way to opt out is _PUBLIC_ROUTER = True at module level.

Making a route public

# lib/api/routes/webhooks.py

_PUBLIC_ROUTER = True          # moves the whole module to the public (no-auth) router
router = APIRouter(prefix="/webhooks", tags=["webhooks"])

@router.post("/stripe")
def stripe_webhook(payload: dict):
    ...

Only use _PUBLIC_ROUTER = True for endpoints that genuinely need no authentication (webhooks with their own signature verification, health checks, etc.).

JWT strict mode

lib/auth/jwt_handler.py checks the secret at module import time. Behaviour depends on JWT_STRICT and API_ONLY:

JWT_STRICTAPI_ONLYDev secret presentResult
falsefalse Yes warnings.warn — app starts, token is forgeable
trueany Yes sys.exit(1) — app refuses to start
anytrue Yes sys.exit(1) — app refuses to start
anyany No Silent — all good

Generate a production secret:

python -c "import secrets; print(secrets.token_hex(32))"

CORS

CORSMiddleware is wired in main.py using config.cors_origins. The comma-separated string is split into a list at startup.

# .secrets/.env
CORS_ORIGINS=https://app.example.com,https://admin.example.com

The defaults (http://localhost:3000,http://localhost:8080) cover the most common dev server ports. allow_credentials=true is set — cookies and Authorization headers work cross-origin.

⚠️ Do not set CORS_ORIGINS=* when using credentials. Browsers reject credentialed requests to wildcard origins. Use explicit origins.

Rate limiting

lib/api/rate_limiter.py implements a sliding-window rate limiter keyed by client IP. It uses Redis (via CacheRegistry) when available, falling back to an in-process dict for single-process and test deployments.

Two limiters are created per make_v1_router call:

LimiterApplies toDefault
login_limiter public sub-router (login endpoint) 5 req/min
general_limiter protected sub-router (everything else) 60 req/min

Exceeding the limit returns HTTP 429 Too many requests.

Custom limiter on a specific endpoint

from fastapi import Depends
from lib.api.rate_limiter import RateLimiter

_strict = RateLimiter(limit=10, window=60)  # 10 req/min, 60-second window

@router.post("/expensive-operation")
def expensive(_, __=Depends(_strict)):
    ...

Auth flow reference

# 1. Login
curl -X POST http://localhost:8080/v1/auth/login \
  -d "username=alice&password=secret"
# → {"access_token": "eyJ...", "token_type": "bearer"}

# 2. Call a protected endpoint
curl http://localhost:8080/v1/users \
  -H "Authorization: Bearer eyJ..."
# → [{"id": "...", "username": "alice", ...}]

The JWT payload contains {"sub": "<user_uuid>"}. get_current_user in lib/auth/dependencies.py decodes it and returns the User ORM object.

Using the current user in a handler

from lib.auth.dependencies import get_current_user, require_roles

# Access current user (already enforced by the sub-router, but useful for audit/ownership)
@router.get("/me/orders")
def my_orders(current_user=Depends(get_current_user)):
    return repo.list(user_id=current_user.id)

# Restrict to a specific role
@router.post("/admin/action")
def admin_action(current_user=Depends(require_roles(["admin"]))):
    ...

Security test coverage

FileWhat it verifies
tests/test_security_contract.py All routes under /v1/; login reachable without Bearer; every other endpoint returns 401 without Bearer
tests/test_security_behaviour.py Full auth flow; 401 on no/bad token; 429 on rate-limit breach
tests/test_security_cors.py Allowed origin gets CORS headers; blocked origin doesn’t; credentials header present

test_security_contract.py is a living regression guard — if a developer adds an unprotected route, test_protected_endpoints_require_bearer_token fails immediately on the next pytest run.
