📐 The Architecture — At a Glance

FlexTemplates follows a LEGO-block pattern where layers talk via contracts, and every piece can be swapped without touching the rest.

🖼️ Views Flet pages
🔌 API Routes FastAPI endpoints
↓
⚙️ Services Business logic
📋 Contracts ActionRequest/Result
↓
🗄️ Repositories Data access (CRUD)
🔄 Adapters Redis, files, external APIs
↓
💾 Database SQLAlchemy ORM

🔄 How Data Flows (Example: Navigation)

Here's what happens when a user clicks a button in Flet:

1

User clicks NavButton

NavButton("Products", "/products")
→
2

Button calls NavigationService

service.execute(ActionRequest(action="visit", data={"url": "/products"}))
→
3

Service publishes Event

EventBus.publish(Event(type="nav.route_changed", ...))
→
4

Adapter listens to Event

FletNavigationAdapter subscribes; calls page.go()
→
5

Router loads view

FletRouter matches "/products" and loads ProductsView
→
6

View renders

page.update() — UI painted

Key insight: NavigationService knows nothing about Flet. FletNavigationAdapter is the only piece with Flet imports. This is the LEGO pattern in action.
